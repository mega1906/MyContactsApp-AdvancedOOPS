# MyContacts App - Advanced OOPS

### Use Case 3 - User Profile Management

This project is a Java console application built step by step using object-oriented programming concepts, design patterns and core Java features.

This use case allows a logged-in user to view and update profile details, change the account password and manage preferences.

#### Design Patterns

- Command Pattern for profile update operations
